# Scrap Library 封面选图与裁切逻辑（最终版）

> 规格文档（产品规则）。实现以本文件为准；代码未对齐时按本文改。  
> 状态：海报字段优先 →（低于 85 补全局）→ URL 升级 → 并发打分早停 → 分区裁切 → 原尺寸 `poster.jpg`

---

## 0. 总架构：两段式

```
① 元数据：并发刮源 → 合并字段 → 写 NFO（只收集封面候选 URL，不下载）
② 封面：NFO 写完后按本方案选图、下载、裁切、落盘
```

- 不硬拼图链；只用各源真实 URL + 升级规则。
- 失败绝不写假成功；队列回写必须按番号 / `logId` 对齐。
- 次成功（缺女优）：同条轻量二次只补女优，补到则升为完整成功。
- 批量封面经独立 cover-job 池（默认 7）调度，与元数据 itemWorkers 解耦。

## 2. 选图与下载

### 2.1 收集候选（勿过早锁死）

1. 先跑「海报字段优先级」→ **优先池**  
2. 若优先池最高分 **≥ 85** → 直接采用，不再补全局  
3. 若最高分 **低于 85**（或优先池全灭）→ 从分区全局池再补 **2～3** 个高优 URL  
4. 合并所有已打分候选，取**全局最高分且合格**落盘  
5. 单番号总尝试仍封顶 **6** URL  

### 2.2 URL 升级（全局）

- `ps.jpg` → `pl.jpg`
- `/thumbs/` → `/covers/`
- `/thumb/` → `/cover/`
- 其它常见小图↔大图规则（`_s`↔`_b`、MGStage `pb`↔`pf` 等）

### 2.3 并发下载 + 评分

| | 批量 | 单刷 |
|--|------|------|
| 封面并发（单番号 URL） | 5 | 6 |
| 整番号封面任务池 | 7（与元数据 itemWorkers 解耦） | 直跑 |
| 元数据 itemWorkers | 6 | — |
| 单 URL 超时 | 3.5s | 5s |
| 早停分数 | ≥78 | ≥75 |
| 单番号最大尝试 URL | 6 | 6 |
| 强制收工 | 已有**能落盘**的合格图且**完成**尝试 ≥4 | 同左 |

每张下载后立即打分；够分早停；已有合格图且试满 4 个 URL 强制收工；最终取**最高分且合格**的图。

### 2.4 评分（总分 100）

| 项 | 分值 |
|----|------|
| 分辨率 | 0~40（宽≥800 且 高≥1100 → 40） |
| 来源类型 | pl=25，ps=12，其它=5 |
| 来源信任/优先级 | 0~20 |
| 宽高比 | 竖图 h/w ∈ [1.4, 1.6] 加分（有码/写真）；无码/国产/欧美要横图 |
| 原生竖 pl | **+8**（鼓励早停留竖图） |
| 常见 DMM 横 pl（约 800×538） | 基础横图分 + **+4** 友好分 |

有码/写真优先原生竖图；无码/国产/欧美只要原版横图。

### 2.5 空白图检测

体积门槛 + 像素抽样：低色彩多样性 / 低方差 / 近白近黑亮度门。

## 3. 分区裁切

| 分区 | 模式 | 行为 |
|------|------|------|
| 有码 / 写真 | `right` | 竖图原样；横图右裁 |
| 素人 / FC2 | `face` | 竖图原样；横图按人脸裁，无人脸则中裁 |
| 无码 / 国产 / 欧美 | `none` | 只要原版横图，跳过竖图 |

铁律：

- 只有宽 > 高才裁  
- 只削左右，不改高度  
- 不缩放，原像素写 JPEG（可选「横图小幅增强」默认关，另议）  
- 目标竖幅约 2.12:3（裁切参考，不强制缩放）

---

## 4. 落盘

- 目录只保留 `poster.jpg`  
- 最小尺寸看**裁切前**源图：宽≥600 **或** 高≥800（覆盖常见 DMM pl ≈590×800 / 800×538）  
- 横图右裁后宽可到 ~380，属正常，不再用裁后尺寸卡死  
- 新图分数明显更高才覆盖旧图  
- 假图 / 空白 / 不合格不落盘  
- **成功回写前强校验**：NFO 存在 + `poster.jpg` 非空且宽≥200、高≥400；否则禁止标成功
