# 六区番号名字格式（数据源测试基准）

后续逐站测源、对番号能否查到时，**以本表为输入形态**。  
实现依据：

- 本仓库：`apps/maps/prefixes/code-read.json`、`code-shapes.json`、`apps/api/app/search/av.py`
- 对照 MDCX：`.refs/mdcx/mdcx/number.py` → `get_file_number`（从文件名抽出番号）

六区顺序与 `apps/maps/regions/regions.json` 一致。

## MDCX 怎么从文件名认出「可用番号」

MDCX **没有单独的「规范格式校验器」**，核心是 `get_file_number(filepath)`：先洗文件名，再用一串正则按类型抽取。本地实测：

| 文件名 | MDCX 抽出 | 含义 |
|--------|-----------|------|
| `SONE-015.mp4` | `SONE-015` | 保留文件名里的位数（**不强制 pad=3**） |
| `SONE-15.mp4` | `SONE-15` | 短号原样保留 |
| `SONE-15-C.mp4` | `SONE-15` | 去掉 `-C` |
| `IPZZ-599C.mp4` | `IPZZ-599` | 去掉末尾分盘字母 |
| `IPZZ-599-C.mp4` / `IPZZ-599A.mp4` | `IPZZ-599` | 同上 |
| `IPZZ-599.CD1.mp4` | `IPZZ-599` | 去掉 `CD` 分集 |
| `ssni00644.mp4` | `SSNI-644` | DMM 五位 CID：`字母+00+三位` → `字母-三位` |
| `FC2-PPV-976194.mp4` | `FC2-976194` | PPV 归一成 `FC2-` |
| `259LUXU-001.mp4` | `259LUXU-001` | 素人数字板号整段保留 |
| `blacked.26.01.15.mp4` | `Blacked.26.01.15` | 欧美点分日 |
| `MDSR-0002-EP3.mp4` | `MDSR-0002` | 分集被洗掉 |

### 洗文件名（抽号前）

```112:124:.refs/mdcx/mdcx/number.py
    filename = (
        file_name.replace("-C.", ".")
        .replace(".PART", "-CD")
        .replace("-PART", "-CD")
        ...
    )
    filename = re.sub(r"[-_ .]CD\d{1,2}", "", filename)  # xxx-CD1
    filename = re.sub(r"[-_ .][A-Z0-9]\.$", "", filename)  # xxx_1 / xxx.A
```

要点：

1. **`-C` / `CD` / 末尾单字母数字分盘 → 一律剥掉**，不进番号  
2. **不把 `SONE-15` 补成 `SONE-015`**；文件名写几位就留几位  
3. DMM 胶合 CID 只认 `XX00NNN` 这种中间 `00` 模式，收成 `XX-NNN`  
4. FC2 统一成 `FC2-{id}`（去掉 PPV）  
5. 类型辅助：`is_uncensored` / `is_suren`（前缀表 + 正则），不负责「规范名」

> 与本仓库差异：我们目录侧用 **pad=3 展示键**（`SONE-015`）；查源时用 `code_equiv` 把短号/补零当成同号。  
> MDCX 弱项示例：`1pondo-062014_830.mp4` 会被抽成错误的 `PONDO-062014`——无码 date6 仍以本仓库 `1PON-062014-830` 为准。

| 区 | `region_id` | 主格式族 | 规范键示例（测源优先用这个） |

## 1. 日本有码 · `japan_censored`

### 规范格式

```
{PREFIX}-{NUM}   # NUM 按 pad 左补零；有码默认 pad=3 → 三位
```

规范键（本仓库目录 / 测源主输入）按 pad 补零，例如 **`SONE-015`**。  
MDCX 从文件名抽出时**不补零**（`SONE-15.mp4` → `SONE-15`），但会剥掉 `-C` / 字母尾；两端都认定：**带 `C`/`A`/`CD` 的不是番号本身**。

| 子类 | `code_read` | pad | 说明 | 规范示例 |
|------|-------------|-----|------|----------|
| DMM 流水 | `std3_dmm` | **3** | 多数厂；CID 侧常再扩成 5 位 | `CLUB-127`、`ABP-900`、`SSNI-015` |
| 开放流水 | `std3_open` | **3** | 可突破 999（四位仍合法） | `SSIS-001`、`SONE-015`、`SONE-850`、`IPZZ-400`、`ABF-051` |

目录统计：有码前缀几乎全是 `pad=3`（`std3_dmm` 为主，`std3_open` 约 44 个）。

### 同号变体（测源要覆盖；非正式规范名）

| 变体 | 例子 | MDCX | 本仓库 |
|------|------|------|--------|
| 短号未补零 | `SONE-15` | 原样保留 | 与规范键 `SONE-015` **等价**（`code_equiv`） |
| DMM 五位 CID | `ssni00644` | → `SSNI-644` | → `SSNI-644` / 再与 pad 键等价 |
| 过长前导零 | `NAMH-0028` | 原样或按正则 | 与 `NAMH-028` 等价 |
| 分盘 / 破解字母尾 | `IPZZ-599C`、`…-C`、`…A` | → **基号** `IPZZ-599` | 同左；**不规范** |
| 分集尾 | `MDSR-0002-EP3`、`…-CD1` | → 基号 | 同左；**不规范** |

### 测源推荐输入（有码）

**规范键（主测）——仅 `PREFIX` + 补零数字，无字母尾：**

```
SSIS-001
SONE-015
ABF-051
IPZZ-599
CLUB-127
```

**变体（兼容测，可选；本身都不算规范名）：**

```
SONE-15
IPZZ-599C
```

## 2. 日本无码 · `japan_uncensored`

无码不是单一 `{prefix}-{num}`。按 shape 测。

### A. date6（一本道 / 加勒比 / 10 娘 / 帕科等）

```
{LABEL}-{MMDDYY}-{NNN}
```

| 规范键 | 站内常见变体（查源常需要对上） |
|--------|--------------------------------|
| `1PON-062014-830` | `062014_830`、`1pondo-062014_830` |
| `CARIB-011317-002` | `011317-002`、`caribbeancom-011317-002` |
| `CARIBPR-011317-002` | `caribbeancompr-…` |
| `10MU-062014-01` | `10musume-062014_01` |
| `PACO-122615-557` | `pacopacomama-122615_557` |

> 目录里部分 date6 行仍写着 `format: "{prefix}-{num}"` + `pad:3`，**那是导出占位，不要当真**；规范以 `date6` / `prefix_format_meta` 为准。

### B. 四位 / 固定流水（fixed_std）

| 前缀 | 规范示例 |
|------|----------|
| HEYZO | `HEYZO-2034`（常四位） |
| KIN8 | `KIN8-3500` |
| TOKYOHOT | `TOKYOHOT-N1234` |
| MESUBUTA | `MESUBUTA-123456-001` |
| HEYDOUGA | `HEYDOUGA-4030-001` |

### C. 字母数字流水（alnum_id）

| 前缀 | 规范示例 |
|------|----------|
| H0930 | `H0930-ORI123` / `H0930-ki260908` |
| H4610 | `H4610-ki260908` |
| C0930 | `C0930-hitozuma1369` |

### 测源推荐输入（无码）

```
1PON-062014-830
CARIB-011317-002
HEYZO-2034
KIN8-3500
H0930-ORI123
TOKYOHOT-N1234
```

## 3. 日本素人 · `japan_amateur`

### 规范格式

```
{PREFIX}-{NUM}
```

| 子类 | `code_read` | pad | 说明 | 规范示例 |
|------|-------------|-----|------|----------|
| 素人四位 | `amateur4` | **4** | `200GANA`、`259LUXU`、`SIRO`、`LUXU` 等组 | `200GANA-0001`、`SIRO-1234` |
| 数字头板号 | 常 `std4` / `amateur4` | **4** | 文件夹可能是 `259LUXU-001` 或剥成 `LUXU-001` | `259LUXU-001` ↔ `LUXU-001` |
| 有码式 | `std3_dmm` 等 | **3** | 部分素人厂仍三位 | `HMDN-332` |

| 变体 | 例子 |

| 带数字板号 | `259LUXU-001` |
| 剥板号后 | `LUXU-001` |
| 短号 / 补零 | `HMDN-332` vs `HMDN-0332`（按该前缀 pad） |

### 测源推荐输入（素人）

```
HMDN-332
200GANA-0001
259LUXU-001
LUXU-001
SIRO-1234
```

## 4. FC2 · `fc2`

### 规范格式

| 形态 | 规范键 | 说明 |
|------|--------|------|
| 目录归一 | `FC2-{数字}` | 落盘 / 丰富主键 |
| 站内常见 | `FC2-PPV-{数字}` | 与上一行 **同号**（`code_equiv`） |

示例：`FC2-976194` ≡ `FC2-PPV-976194` ≡ slug `fc2-ppv-976194`。

### 测源推荐输入（FC2）

```
FC2-976194
FC2-PPV-976194
```

## 5. 国产无码 · `china`

### 规范格式

```
{PREFIX}-{NUM}
```

- **不要全区强制 4 位**：按厂牌实际帖题 / 目录 `pad`。
- 数字头国产前缀（如 `91CM`）解析时**保留**板号，勿剥成 `CM`。
- 分集：`MDSR-0002-EP3` → 基号 `MDSR-0002`。

| 例子 | pad 习惯 | 规范示例 |
|------|----------|----------|
| 麻豆等四位 | 常 4 | `MDSR-0002`、`91CM-0001` |
| 短流水 | 常 3 | `JD-150`（不要写成 `JD-0150` 除非源站如此） |

### 测源推荐输入（国产）

```
91CM-0001
MDSR-0002
JD-150
MDSR-0002-EP3
```

## 6. 欧美无码 · `western`

### 规范格式（主）

```
{STUDIO}.{YYYY}.{MM}.{DD}
```

| 可接受输入 | 归一后 |
|------------|--------|
| `BLACKED.2026.01.15` | 同左 |
| `BLACKED.26.01.15` | `BLACKED.2026.01.15` |
| `BLACKED-26-01-15` | `BLACKED.2026.01.15` |
| `BLACKED-260115` | `BLACKED.2026.01.15` |

次要：`STUDIO.YYYY.MM`（月号）、`STUDIO.YYYY`（年号）— 覆盖较弱，主测用完整日。  
站点侧：AVHeat 等常展示 **两位年** `STUDIO.YY.MM.DD`；刮削用 `western_code_candidates` 双试。

### 测源推荐输入（欧美）

```
BLACKED.2026.01.15
BRAZZERS.2024.06.01
VIXEN.2023.11.20
BrazzersExxtra.26.07.09
```

## 共用剥壳（所有区测源前先心里过一遍）

| 规则 | 做 | 不做 |
|------|----|------|
| 大小写 | 统一按大写比 | — |
| 分隔符 | `-` `_` `.` 在等价判定里常忽略 | 欧美规范键用 **点** |
| 分盘字母 | 查源用基号；`…C` / `…A` / `…-CH` **不算规范名** | 把 `IPZZ-599C` 写成规范键或当另一部 |
| 分集 | 丢掉 `-EP3` / 末段短集号 | 误剥 `SONE-15` 的 `-15`（已修正则） |
| pad | 短号与补零同号；**规范展示一律按 pad 补零** | 把 `SONE-15` 当规范名 |

## 最小矩阵（一站测完这 6 行再下结论）

按区各抽 1～2 个规范键；源声称不适配的区可标 SKIP，不要强求命中。

| 区 | 必测规范键 | 可选变体 |
|----|------------|----------|
| 有码 | `SSIS-001`、`SONE-015`、`IPZZ-599` | `SONE-15`、`IPZZ-599C`（短号/字母尾，兼容测） |

| 素人 | `HMDN-332` + `259LUXU-001` | — |
| FC2 | `FC2-976194` | `FC2-PPV-976194` |
| 国产 | `MDSR-0002` | — |
| 欧美 | `BLACKED.2026.01.15` | — |
